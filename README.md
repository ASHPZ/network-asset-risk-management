# 🛡️ IT Asset Inventory and Classification

## 📌 Project Overview
This project demonstrates the process of identifying, cataloging, and classifying IT assets within a small network environment. Proper asset management is a foundational step in establishing robust cybersecurity protocols and ensuring that sensitive data is protected according to the principle of least privilege.

## 📖 Scenario
I acted as a junior cybersecurity analyst for a small organization. The objective was to create a comprehensive asset inventory that maps devices and data points to specific security classifications. This ensures that the organization can accurately track what needs protection and who requires access.

## 🛠️ Methodology & Actions Taken
1. **Asset Identification:** Mapped all network endpoints, including continuous and occasional connections (e.g., routers, endpoints, IoT devices).
2. **Access Evaluation:** Determined network access frequency and owner accountability for each asset.
3. **Data Classification:** Assigned sensitivity levels (*Public, Internal-only, Confidential, Restricted*) based on the type of data stored or processed by the asset.
4. **Access Designation:** Established logical access controls (e.g., *Anyone, Users on-premises, Need-to-know*) aligned with the assigned sensitivity levels.

## 📊 Results & Artifacts
The final deliverable is an organized matrix that maps each physical and logical asset to its appropriate security posture.
